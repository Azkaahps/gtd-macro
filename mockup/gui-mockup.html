Mockup GUI v2 — ANON GTD v1.2.0

Klik tab / toggle / slider di kiri. Tombol ⤢ di header buat lihat dua mode shell: panel mengambang di atas gameplay ⇄ layar penuh. Tombol — meringkas jadi bar. Tekan RECORD buat lihat state rekaman.

Keputusan yang sudah masuk mockup ini

1
Farm pakai replay input. Tab Match & Auto Mode tidak menembak remote — Skip Wave menekan tombol skip di layar, Auto Ability menekan skill, semuanya lewat jalur input yang sama dengan recorder. Ada bar “engine:” di atas tiap tab.
2
Telemetry & Dashboard API dibuang total. Section “Dashboard API” hilang; tab Webhook tinggal Discord webhook + Target + Ringkasan, plus kartu “Keamanan” yang menyatakan itu eksplisit.
3
Panel mengambang + expand ke sheet. Default: panel di atas gameplay (bisa diringkas jadi bar). Tombol ⤢ bikin dia edge-to-edge buat menu banyak.
4
Humanizer default 4 px / 25 ms. Slider dinaikin (posisi 0–6 px, waktu 0–60 ms) dengan nilai default baru.

TambahanKenapa
Live strip di atas tabwave · T+ sejak ronde · steps · stempel konteks (mode/diff/map/speed + sumbernya). Ard Hub tidak punya status live.
Macro History (bukan cuma dropdown)daftar dengan stempel lengkap, PIN, GO, rename, export, delete — plus filter & pinned-only.
Wave-anchored replay · Verify placement · Speed mismatchtiga penjaga supaya replay tidak meleset: jangkar per ronde, verifikasi unit mendarat, dan skala/penolakan kalau speed beda.
Humanizer (jitter px + ms)Ard Hub punya “Placement Spread” saja; kita jitter posisi & waktu.
Diagnosticsfile api, folder, file di disk, isi index, memory-only, RESCAN DISK, COPY REPORT — penjawab “udah rekam tapi gak muncul”.
Panel ringkas otomatis saat recorddi HP panel kebuka nutupin layar; bar mini `ANON ● REC n ▲` + pill STOP.
Rencana implementasi (Luau, Instance-based): UI-nya gue tulis ulang jadi builder deklaratif (section / toggle / slider / input / dropdown / button), tiap tab cuma array definisi. Mesin yang sudah jalan (recorder, replay, history, diagnostics, anchors) dipindah tanpa diubah perilakunya, lalu tiga modul baru: tap-actions (skip wave / ability / difficulty lewat tap terverifikasi), webhook (POST ke URL Discord lu, butuh request di executor), dan loops / auto-return. Semua tetap di belakang harness yang sama — check harus hijau sebelum gue push.
